## 2. LINE でのお知らせ（今井の LINE 公式アカウント）

### 仕組み
- 今井が **LINE 公式アカウント**（無料のプラン）を作る。大学の公式でなくてよい。
- アプリのホームとマイページに「**LINE で友だち追加**」のボタンを出す（`oshifit-study/public/config.js` の `OSHIFIT_LINE_URL` に友だち追加の URL を入れると出る。空なら出ない）。
- 友だち追加は参加者が自分で選ぶ（任意）。**研究の記録と LINE はつながない**：LINE で研究用の番号や回答を聞かない。お知らせは友だち全員に同じ文を送る（一斉配信）。
- 個人の LINE（今井のアカウント）やグループは使わない：参加者どうしが見えてしまい、今井の個人のアカウントも知られるため。

### 作り方（今井がする）
1. 「LINE公式アカウント」で検索し、LINE Official Account Manager でアカウントを作る（個人で作れる。業種は「教育」など）。
   - アカウント名の例：`OshiFit（推し活の研究）`
2. 「ホーム」→「友だちを増やす」→「友だち追加ガイド」で、**URL**（`https://lin.ee/…`）をコピーする。
3. その URL を `config.js` の `OSHIFIT_LINE_URL = "https://lin.ee/…";` に入れて、いつもの手順でデプロイする。
4. 「あいさつメッセージ」と「応答メッセージ」を下の文に変える（自動の返事は、決まった文だけにする）。

### 送れる数（2026年11月時点の LINE の案内で確かめること）
- 無料のプランは、**1か月に送れるメッセージの数に上限**がある（友だち1人に1通で1通と数える）。例えば上限が200通で友だちが20人なら、一斉配信は月10回まで。
- そのため、毎日送るのではなく、**週2〜3回**（振り返りが開く日の目安など）に絞る。参加者が増えて足りなくなったら、送る回数を減らす。
- 参加者は、毎日のアンケートの時刻を「カレンダーに追加（.ics）」で自分のスマホに入れられる（ホームにある）。毎日のお知らせは、こちらを案内する。

### あいさつメッセージ（友だち追加のとき）

```
友だち追加ありがとうございます！
OshiFit（推し活の研究）の今井です。
このアカウントから、毎日のアンケートや振り返りのお知らせを、ときどきお送りします。

・アンケートと振り返りは、アプリから答えてください
　https://oshifit-34941.web.app
・研究用の番号や回答の内容は、LINE では聞きません。送らないでください
・お知らせが不要になったら、いつでもブロックしてかまいません（研究への参加には影響しません）

問い合わせは、アプリのマイページにあるメールアドレスへお願いします。
```

### 応答メッセージ（参加者が何か送ってきたとき）

```
メッセージありがとうございます。
このアカウントは、お知らせ専用です。個別のお返事はできません。
問い合わせは、アプリのマイページにあるメールアドレスへお願いします。
つらいときは、アプリのホームの「相談先を見る」から相談先を開けます。
```

```
https://oshifit-34941.web.app
```

### 気をつけること
- 一斉配信は、始めた日が人によって違うので、「今日が振り返りの日です」のような**個人あての言い方はしない**（上の文は、誰が読んでもおかしくないようにしてある）。
- LINE で届いた個人の情報（研究用の番号・つらい内容など）は、研究のデータにしない。つらい内容が届いたら、相談先を案内する。
- 参加者への連絡の方法を増やすので、倫理審査で承認された内容（参加者への連絡の方法）と合っているかを確かめる。
