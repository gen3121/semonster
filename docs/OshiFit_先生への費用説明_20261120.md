OshiFit の提案を、参加者の推し（例：阪神タイガース）に合わせた文にするため、研究室の ChatGPT の API を使わせていただきたく、費用の見込みをまとめました。

【使い方】
・参加者が質問紙を終えたときに1回だけ、提案文（最大3つ）を作ります。作った文は保存し、あとは同じ文を表示します。
・送る内容は、6つの軸の点数・推しのジャンル・推しの名前・推しの数・使うお金の範囲だけです。氏名・メールアドレス・自由記述は送りません。
・OpenAI の API に送った内容は、モデルの学習に使われません（OpenAI の利用規約による）。
・API が使えないときは、今ある15種類の固定の提案文を表示するので、実験は止まりません。

【費用の見込み】（1ドル＝155円で計算）
1回あたり：入力 約4,000トークン、出力 約3,000トークン（考える部分を含む）
・GPT-6.2 Sol（予定）：1回 約6円
・GPT-6.2 Astra（最上位）：1回 約24円

| | Sol（予定） | Astra |
|---|---|---|
| 参加者100人（作り直しの予備を含め150回） | 約900円 | 約3,600円 |
| 動作確認・デバッグ（約200回） | 約1,200円 | 約4,800円 |
| 合計 | **約2,000円** | 約8,500円 |

参加者が200人になっても、Sol で約3,000円の見込みです。

【Firebase について】
API の鍵をアプリの中に置かず、サーバー側（Cloud Functions）で安全に管理するため、Firebase を従量課金の Blaze プランに変えます。
参加者の人数では無料の範囲（月200万回の呼び出しなど）に収まるため、費用はほぼ0円の見込みです。念のため、1,000円で通知が来る予算の通知を設定します。

【お願い】
・研究室の OpenAI のアカウントに、OshiFit 用の「プロジェクト」と鍵を作っていただけますか。月の上限（例：3,000円）を設定しておけば、想定より多く使うことはありません。研究室の他の利用とも分けて確認できます。
・鍵は Firebase の秘密の保管場所（Secret Manager）にだけ入れ、リポジトリやチャットには書きません。

ご確認をお願いいたします。
