## 1. 研究課題名（案）

推し活の頻度の見直しを支援する対話型アプリの効果の検討（OshiFit）

## 2. 研究の目的と意義

- 推し活は楽しみや生きがいになる一方、睡眠・お金・義務感・他のファンとの比較による負担（推し疲れ）につながることがある。
- 予備調査（大学生215名）で、推し活の頻度と、幸福度（生きがい・自信など）・推し疲れ（睡眠・金銭の不安など）が関連することを確認した。
- 本研究は、本人が答えた「いちばん幸せな推し活の頻度」を手がかりに、頻度を少しだけ見直す提案を行うアプリが、6週間の幸福度と推し疲れに与える影響を調べる。
- 提案は強制せず、いつでも見送れる。診断や治療を目的としない。

## 3. 研究期間と日程（案）

- **承認日〜2027/03/31**（研究期間）。承認前にはデータ収集を行わない。
- 参加者1人あたり **6週間**（最初の2週間は全員「記録のみ」、その後の4週間で群ごとの画面）。
- 6週間が研究期間に収まるよう、**最後の参加者の開始日は 2027/02/17 まで**（3/31 から42日戻した日）。解析・データ削除の時間を考えると、データ収集は **2027/02/末まで**に終えるのが安全。【要確認：申請上のデータ収集の終了日】
- 例：承認後すぐに募集 → 参加者ごとに開始 → 2027/02/末 データ収集終了 → 2027/03 解析・匿名化・不要データの削除 → 2027/03/31 研究期間終了。

## 4. 研究の対象者

- 選択基準：18歳以上の、推し活（アイドル・VTuber・アニメ・ゲームなど）をしている大学生・大学院生。
- 除外基準：18歳未満。現在、精神科・心療内科などで治療中で、参加が負担になる可能性があると自分で判断する人（参加前にそのように説明する）。
- 人数：【要確認：予備調査と先行研究から決めた人数と、その根拠】
- 募集：【要確認】。研究室の指導関係にある学生を募集する場合は、成績や評価と無関係で、断っても不利益がないことを明記する。

## 5. 研究の方法

1. **同意**：アプリの最初の画面で説明文書を見て、同意する場合だけ進む。
2. **初回の質問（約10分）**：質問紙と同じ項目を、会話形式で答える。ボタンで答えても、自由な文で答えてもよい。性格（TIPI-J）、アバターへの意識、推し活の頻度と理想の頻度、推し疲れ4項目、推し活の効果4項目、お金と時間の目安、WHO-5（気分）。
3. **毎週（約3分）**：いまの頻度、推し疲れ、推し活の効果の12項目。2週ごとに WHO-5。
4. **群への割り付け**：最初の2週間のあと、研究者が無作為に3群に分ける。
   - A群：記録のみ（比較のための群）。
   - B群：文章での提案。
   - C群：文章での提案＋「いまの状態」のグラフと予測、似顔アバターによる比較。
5. **提案の内容**：理想の頻度より少なくなる変更は出さない。最適度（理想とのずれ）が80%以上の人には、1段階だけの微修正を出す。「見送る」はいつでも押せる。見送った人も、同じ毎週の質問を続ける。
6. **終了後**：6週間後の最終の質問に答える。A群にも、研究終了後に希望すれば同じ提案を見られるようにする（5-1 参照）。【要確認：提供方法】
7. **アバター**：パーツで作る。希望する場合だけ、写真から似顔絵を作る機能を使える。写真は端末の中だけで処理し、保存も送信もしない。
8. **予測の表示**：予備調査にもとづく「見込み」で、効果を保証するものではないことを画面に常に表示する。

## 6. 倫理的配慮

### 6-1 リスクと対策

| 想定されるリスク | 対策 |
|---|---|
| 質問への回答で気分が落ちる・つらくなる | 参加は任意。いつでも中断・撤回できる。つらさが強いと見られる言葉、WHO-5 の低得点（素点13未満）、推し疲れが強い状態が続くときは、予測や提案を止めて、相談先（学生相談室・公的な相談窓口）を表示する。診断や助言は行わない。 |
| 提案に従わなければならないという圧力 | 提案は「見込み」であることを明記し、「見送る」を常に表示する。見送った人も同じように参加でき、不利益はない。見送りの理由の回答は任意。 |
| 推し活を減らすことへの抵抗 | 本人が「増やしたい」と答えた活動は減らす提案を出さない。「すでにほぼ最適です」と表示する場合もある。 |
| 対照群（A群）が提案を受けられない不公平 | A群にも、研究終了後に希望すれば提案を見られるようにする。【要確認】 |
| 研究者や指導教員との関係で断りにくい | 対象者の募集で、参加の可否が評価・成績と無関係であること、断っても不利益がないことを書く。回答は匿名IDで扱い、個人を特定して指導教員に伝えない。 |
| 未成年への影響 | 18歳以上のみを対象にする。 |

### 6-2 個人情報とデータの管理

- 氏名・メール・学籍番号は収集しない（連絡が必要な場合は別の同意を取る。【要確認】）。回答は参加者ごとの匿名IDで管理する。
- 自由な文章そのものは保存しない。読み取った回答の数字だけを残す。
- 写真は保存・送信しない。端末の中で、顔の特徴点から色と比率の数値だけを出し、写真はすぐに破棄する。
- 保存先・保存期間：【要確認】。研究期間の終了後、個人が特定できないよう匿名化し、不要な生データを削除する時期を明記する。
- 同意の撤回：撤回の連絡があった場合、その人のデータを削除する（匿名化後は削除できないことを事前に説明）。

### 6-3 外部の AI（大規模言語モデル）の利用【審査で最も聞かれやすい点】

- アプリには、自由な文章を質問紙の項目の回答に直す「AI読み取り」がある。これは**任意**で、同意画面で本人が選んだ場合だけ使う。選ばなくても、すべてボタンと短い文で答えられる。
- 使う場合、文章を**電話番号・メールアドレス・URL・住所・SNSの@名などを伏せたうえで**外部の AI のサービス（Anthropic 社の Claude API）に送る。サーバーに文章は保存せず、ログにも残さない。APIキーは参加者の端末には置かない。
- 外部事業者に渡るのは、伏せ字にした文章だけで、個人を特定できる情報は含まれない。
- 外部事業者のデータの扱い（学習への利用の有無、保存期間）：【要確認：契約・利用規約の確認結果を記載】
- **審査対策の選択肢**：外部送信の承認が難しい場合は、AI 読み取りを使わず、規則とボタンだけで実施できる（アプリはそのまま動く）。申請書は「AI読み取りは任意」とし、委員会の判断でオフにできる形で書いておくと、却下されにくい。

### 6-4 結果の扱い

- 予測や「いまの状態」は、診断ではなく目安であることを画面に表示する。
- 研究の結果は、個人が特定されない形でのみ発表する。

## 7. インフォームド・コンセント（説明文書の要点）

1. 研究の目的、方法、期間（6週間）、時間の負担（初回約10分、毎週約3分）。
2. 参加は任意で、いつでも理由なく中断・撤回でき、不利益がないこと。
3. 研究に参加することの利益（自分の推し活を見直す機会）と不利益（質問に答える時間、気分が落ちる可能性）。
4. 3群への無作為の割り付けがあること（どの群になるかは、最初の2週間のあとに決まる）。
5. 提案は見込みで、効果を保証しないこと。見送ってよいこと。
6. 収集する情報、保存先・期間、匿名化、写真を保存・送信しないこと。
7. AI読み取りを使う場合は、伏せ字にした文章を外部のAIサービスに送ること（任意）。
8. つらくなったときの相談先、問い合わせ先（研究者・指導教員・委員会）。
9. 謝礼：【要確認】。

## 8. 却下されやすい点と、先回りの対策

| 却下・差し戻しされやすい点 | この草案での対応 |
|---|---|
| 外部へのデータ送信が不明確 | 6-3 で、送るもの・送らないもの・任意であること・オフにできることを明記 |
| 参加を断りにくい（学生と研究室の関係） | 募集の方法と、不利益がないことを明記（4、6-1） |
| 心の健康への配慮が不十分 | 検知と相談先の表示、診断をしないこと、WHO-5 の基準を明記（6-1） |
| 無作為割り付けで対照群が不利益 | A群へ終了後に提供（6-1）【要確認】 |
| 研究期間と実験の日程が合わない | 3 で、最後の開始日を 2027/02/17 までとして日程を逆算 |
| データの保存・削除が曖昧 | 6-2 に匿名化・削除・撤回の扱いを記載【要確認：保存先と期間】 |
| 効果を保証するような表現 | 「見込み」「保証しない」を画面と説明文書に明記 |
| 写真の取り扱い | 保存・送信しない、任意、端末内の処理であることを明記 |
