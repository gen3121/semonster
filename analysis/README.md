# 予備調査データの解析（予測モデル v1.0 と基準分布）

元データ（xlsx）にはメールアドレスが含まれるため、**リポジトリには入れていません**。ここにあるのは、匿名化・集計した結果とコードだけです。

```bash
python prepare.py <元のxlsx> <匿名化した表.csv>      # メール・時刻は読み込まない。234名 → 217名 → 215名
python model_v1.py <匿名化した表.csv> <出力フォルダ> cur_media,cur_live,cur_goods,cur_sns,avatar,trg_escape,trg_reward,trg_payday,trg_rebound,trg_recover
```

必要なもの：Python 3、numpy、pandas、scikit-learn、openpyxl。

## 回答の向き（重要）

回収データは **「1＝よく当てはまる／高頻度」** の向きでした。`6 − x` で「大きいほど高い」にそろえています。
根拠：逆向きに読むと、以前の報告の数字と一致します（順方向だと「生きがい」は12%）。

| 項目 | 以前の報告 | 逆向きで読む |
|---|---|---|
| 推しが生きがい | 約8割 | 79% |
| 予算を超えて不安 | 約4割 | 40% |
| 睡眠への支障 | 約3割 | 33% |
| ライブを増やしたい／グッズを増やしたい | 39%／36% | 39%／36% |
| SNSを減らしたい | 22% | 22% |

TIPI-J も同じ向きで回収されていると考えられます（「思いやりがある」の平均が 2.04 など）が、**フォームの選択肢の文言で確認してください**。

## 標本

215名（学生 213名・男性 113・女性 94・その他/回答しない 8）。年齢の中央値 19歳（1歳と書いた回答が2件あり、入力ミスと思われる）。
**社会人はほとんどいません。** 結果は大学生にしか当てはまりません。

## 指標

| 指標 | 項目 | α |
|---|---|---|
| 幸福度（推し活の効果） | 生きがい・自信・スケジュール管理・創作スキル | 0.57（低め） |
| 推し疲れ | 睡眠・予算超えの不安・義務感・嫉妬・落胆 | 0.70 |

幸福度の4項目は、まとまりが弱い（α 0.57）。1つの得点にまとめることの妥当性には注意が必要です。

## 予測の精度（10分割交差検証 × 20回、リッジ回帰）

| 特徴量 | 幸福度 R² | 推し疲れ R² |
|---|---|---|
| F1 現状の頻度4つ | 0.15 | 0.02 |
| F2 ＋理想との差4つ | 0.13 | 0.01 |
| F3 ＋アバター意識・スイッチ | 0.17 | 0.08 |
| F4 ＋性格（TIPI-J） | 0.19 | 0.09 |
| **F5 現状の頻度＋アバター意識・スイッチ（採用）** | **0.19** | **0.10** |

- 誤差（RMSE）は幸福度 0.71、推し疲れ 0.89。何も使わず平均で予測したときの誤差（0.83／0.97）からの改善は小さい。
- 計画書の「説明率 約27%／約11%」より、交差検証の R² は低い（誤差の大きさは計画書の ±0.71／±0.92 と一致）。計画書の説明率は、学習に使ったデータ内の値だった可能性がある（要確認）。
- **「理想との差」は予測に効かない**（相関 .13 以下）。「理想と現実の乖離が幸福度を下げる」仮説は、この標本では支持されなかった。
- 性格との相関は絶対値 .18 以下。
- **これは横断データの関連であり、頻度を変えたときの効果ではありません。** アプリの「提案どおりの見込み」は、この関連にもとづく見込みです。

## 出力

- `prototype/data/norms.json` … 215名の基準分布（項目ごとの人数、指標の三分位）
